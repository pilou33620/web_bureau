Connecter l'iPad

  1. 1. Installer le certificat (une seule fois)

    Visez ce code avec l'appareil photo de l'iPad et touchez le lien. Safari propose de télécharger un profil : Autoriser.

    Puis, dans les Réglages de l'iPad : Profil téléchargé › Installer, puis Général › Informations › Réglages des certificats : activez « web_bureau (CA locale) ».

  2. 2. Appairer l'iPad

    Visez ce code : la page s'ouvre avec le code déjà saisi, et l'iPad est autorisé.

    ––– –––

    Ou ouvrez et saisissez le code.

  3. 3. En plein écran

    Dans Safari : Partager › Sur l'écran d'accueil, puis ouvrez web_bureau depuis l'écran d'accueil de l'iPad.

    iPad Pro, 120 images par seconde : Réglages › Apps › Safari › Avancé › Feature Flags, coupez « Prefer Page Rendering Updates near 60fps ».

Réservez l'adresse du Mac dans votre box, pour qu'elle ne change pas.
